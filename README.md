# 我的 2.5D 小屋（LIFEONLINE）

一款单文件的等距视角生活模拟小游戏：**经营自己的小屋，在小区里上班、买菜、交房租、串门装修**。
客户端是一个可以双击打开的 HTML，服务端是可选的 Go + SQLite 存档服务。

> 当前版本 **1.78.0** · 存档结构 **schema 22** · 门禁：客户端回归 **448 项** / 服务端自测 **67 项** /
> 内容校验 **30 包**全绿（V1–V4.33）· 人物 **25 人**（13 种职业）· 街区 **88×48**

## 直接玩

双击 `dist/2.5D小屋.html` 即可（单文件，引擎与内容都内联，离线可玩）。
存档自动保存到 `localStorage`；如果服务端在跑，会同时同步到云端。

想连服务端：

```bash
cd server && ./home-server.exe        # 127.0.0.1:8787，数据库 server/data/home.db
```

然后打开 `dist/2.5D小屋.html`。没开服务端也能玩，只是不会有排行榜和串门。

```
content/                 内容层（唯一真相）：30 个 JSON 包

  house/                  房型（8 种）、地板墙面风格、住址与房态
  maps/                   家 / 街区地图（88×48，分区、围栏、信箱、传送门、公交站）
  careers/                职业岗位（日薪、班次、任务、熟练等级规则）
  characters/             25 个人物的外观与身份、13 种职业表、聊天话题包
  environment/            随机物、天气、车流；每日广播与街坊闲聊台词
  rules/                  生存规则、经济规则、账单模板
  lottery/ vehicles/      双色球、车款
  business/               可承包的门面（门牌号、承包金、日收益）
  bank/ stock/            银行存款与贷款、六支股票的行情参数
  pets/ interaction/      宠物与交互动词
  achievements/ ui/       生活目标、界面文案、对话表现参数
assets/                   SVG 素材（家具）
tools/                   内容校验与打包、构建、无头回归、各类体检脚本

dist/                    构建产物（core.bundle.js + 单文件 HTML）

```

## 怎么改

**改内容**（家具价格、工资、房价、账单周期、地图分区、台词……）——只动 `content/` 下的 JSON，不用碰代码：

```bash
node tools/content.mjs validate   # 校验：引用完整性、数值合法性（V1–V4.33）
node tools/content.mjs all        # extract → validate → bundle（生成服务端用的 content.json）
node tools/build.mjs              # 生成 dist/core.bundle.js 与单文件 HTML
```

**热更新范围**：改 `catalog/` `house/` `ui/` 的内容，玩家刷新时会就地替换（不刷新页面）；
改 `characters/` `maps/` `rules/` 需要重新加载页面——这些在启动时被建成对象图，假热更会"看着新、用着旧"。

**量一下再改**：想动架构先看状态清单，别凭印象重构。

```bash
node tools/statemap.mjs           # 顶层可变状态：谁写了多少次、有没有入档
node tools/statemap.mjs --top 15  # 只看写入最多的（"上帝状态"候选）
```

**量一下再改**：想动架构先看状态清单，别凭印象重构。

```bash
node tools/statemap.mjs           # 顶层可变状态：谁写了多少次、有没有入档
node tools/statemap.mjs --top 15  # 只看写入最多的（"上帝状态"候选）
```

**跑门禁**（提交前一套）：

```bash
node tools/guard.mjs              # 提交前体检：行尾被翻、行数暴涨、同一行重复 8 次以上
node tools/doccheck.mjs           # 文档数字对账：README 写的包数/家具/人物…和内容包实算是否一致
node tools/dupcheck.mjs           # 重复的顶层函数 / 测试分组；三处年龄枚举是否一致
node tools/charcheck.mjs          # 撞衫：年龄/性别/制服/配饰/发型五项全同的两个人
node tools/genidentity.mjs --check # 身份体检：小孩上班、护士在便利店收银这类不合理
node tools/test.mjs               # dist 与 src 各跑一遍（448 项），用无头 Edge
node tools/test.mjs dist          # 只跑构建产物
cd server && ./home-server.exe -selftest   # 服务端接口自测（进程内 httptest）
```

**调观感**（气泡大小、台词停留时长、闲聊频率、问路范围）改 `content/ui/talk.json`，
不要回去翻绘制代码；这三万字的老毛病是"同一批数字散在两处"。

**编译服务端**（改了 `main.go` / `schema.sql` 必须重编，`schema.sql` 是 `go:embed` 进去的）：

```bash
cd server
GOFLAGS=-mod=mod GOPROXY=off GOSUMDB=off go build -o home-server.exe .
```

详见 [`server/README.md`](server/README.md)（含本机 Go 工具链路径、代理污染、老库迁移的排错记录）。

## 设计要点

| 主题 | 做法 |
|---|---|
| **数据驱动** | 引擎不写死任何数值。加一件家具、一个岗位、一种账单，只加 JSON，校验器会在写错时拦下来 |
| **纯函数推导** | 房态（待售/待租/空置）、车流位置、红绿灯相位都由稳定散列或时间函数现算，服务端不必为 72 间空房各存一行 |
| **存档全自动** | 10 秒定时 + 关键动作即时存 + 关页面前补存；本地优先，防抖推云端，断网进队列 |
| **服务端不当真** | `data_json` 原样保留（新字段不丢），但 `cozy_score` 由服务端按内容重算，越界数值夹紧并标记 |
| **统一世界时钟** | 全服共用一个游戏日（默认 1 天 = 24 分钟真实时间），账单周期与「每天只能上一次班」都挂在它上面 |
| **经济闭环** | 上班（日薪 100–200）→ 吃饭/房租/水电/看病/买车/买房 → 卖车 60%、卖房 70%、卖家具 50% 回收；房里有家具时还能「带装修卖」，家具按 65% 打包折现、一次结清（比零卖划算，但拿不回实物） |
| **钱生钱** | 10 个门面可按月承包（¥1,200–26,000/月），期内每天结算净收益；**全局独占**由服务端 `businesses` 表保证，一个门牌只能有一个老板 |
| **收支账本** | 点金钱条打开：今日收入/支出/净额、近 7 天双色柱、当天分类结构、最近 12 条流水。全部收支走同一个 `credit/debit` 入口，记账不参与任何数值判定 |
| **人物有身份** | 每个 NPC（和玩家）身上都有三个字段：**年龄阶段**、**性别**、**职业**（13 种，带名字与默认制服）。台词据此挑人：小孩不聊房租、厨子才聊后厨。职业表里写着"这行收什么年龄、能在什么地点、具体哪一家"，所以**随机安排身份也不会让小孩跑去上班、护士在便利店收银**（`tools/genidentity.mjs --check` 体检，V4.30/V4.31 拦） |
| **认得出谁是谁** | 人物分三层：**年龄**（儿童/青年/中年/老年四阶段，改头身比与眼睛大小）、**性别**（肩宽 + 睫毛）、**职业**（制服层）。再加 **11 种发型**（短发/中发/长发/卷发/双马尾/短刺/丸子头/齐耳/高马尾/短寸/麻花辫）和剪影配饰（围裙/发带/挎包/手提袋/围巾/拐杖），25 个角色一眼能分清；脸上还能挂胡茬 / 小胡子 / 络腮和耳环。制服分七档（围裙/厨师双排扣/店员马甲/衬衫领带/白大褂/肩章/反光条），25 人两两比对 **300 对没有一对五项全同** |
| **人物有剪影** | 25 个角色各有一条剪影线索：围裙 / 发带 / 挎包 / 手提袋 / 围巾（颜色本来就各不相同）。全身加了统一轮廓线，在花砖和树影里不会糊成一团；配饰进缓存键，改一个人不会**传染**整条街 |
| **能打听事** | 点开任何一个人是一张**问话菜单**：打个招呼 / 你是做什么的 / 最近怎么样 / 哪儿招人 / 打听小区 / 附近有什么 / 现在几点了 / 先走了。答案按「他自己的台词 → 职业 → 年龄阶段 → 通用」取，**时间和方位是真的**（"十点四十了，街上人刚多起来"、"往东走两步，民生银行就在那儿"）；「哪儿招人」报两家正在招人的店，今天上过班就劝你别硬撑；「打听小区」说的就是当天那条广播。全预设词，秒回、离线可用 |
| **街坊会自己搭话** | 两个站得够近的人（店员/邻居）会自己聊起来，附近没人时改嘀咕一句；**纯表现层**——不写存档、不动数值。42 组对聊 + 27 句独白，认身份、认时段、认天气；一次只显示一个气泡，长句按"均分"折行并避开行首标点 |
| **每日广播** | 每天跨天时播一条「小区广播」（电梯检修 / 旧物交换 / 谁家丢了猫），按游戏日稳定散列挑，同一天读档重进还是同一句；雨天有单独的池子 |
| **熟客好感** | 跟同一家店来往会攒好感（每天最多 +2）：打招呼、问这家店、在这家买东西、在这家上班都算。三级：脸熟 → **熟客（到店 95 折）** → **朋友（92 折）**，等级和折扣都写在内容里。**好感按店铺记**，不是按人；网购不参与，避免和 88 折叠加套利 |
| **熟练等级** | 每上满 `shiftsPerLevel` 个班升一级（岗位可覆盖），封顶 `maxLevel`（5 级）。每级单价 **+10%**，满级日薪比新手高 30%–39%（15 个班 ≈ 6 小时真实时间换来的）。面板直接写「Lv.2/5 · 再 1 班升 Lv.3」，不用玩家猜 |
| **小店能买了** | 便利店（饭团/关东煮/罐装咖啡）、咖啡店（美式/拿铁/可颂）、奶茶店（珍珠奶茶/柠檬水/蛋糕）、菜市场（只卖食材包）都有柜台了；这几家同时招人，柜台底下直接「打卡上班」，不会因为加了货架就上不了班。**打烊时间柜台真的收起来**（招牌同步变暗），急用只能去 24 小时的便利店 |
| **空地上有人** | 学校门口等家长的小孩、球场打球的少年、公园下棋的老人、沙地玩的孩子——四个「场所 NPC」按各自作息出现，台词只讲那块地方的真话。公园、球场、东侧沙地不再是一片空地 |
| **店里有店员** | 16 家店各家一个店员，站在自己门口、按各自时间上下班（便利店 24 小时、银行 9–17、证券 9–15）。能打个招呼，也能问「这家店怎么用」——新手不知道柜台能点的时候，问一句比翻说明快。人下班了招牌会跟着暗下去，深夜的街和白天不一样。第一次见面说初识那句，之后就换成熟人的话，他记得你 |
| **邻居有人味** | 五个 NPC 各有各的语气（老王短句、阿芳长句带感叹号、小杰带停顿、王婶爱劝人、老周爱打比方），台词按**时段**（早/昼/傍晚/夜）和**下雨**分池，第一次见面有专属台词且只说一次；聊天时台词挂在对方头顶、情绪反馈挂在自己头上；另有 16 个店员和 4 个场所 NPC 共用同一套渲染与作息 |
| **能坐公交** | 中央大道两头各一个站牌（西站 / 东站），走旁边点它花 ¥2 上车，**车会真的沿马路开过去**（约 3.5 秒，镜头跟车并看向前方，中途报一次站）——窗外能看见开过的快递车和警车；车上不能走动 |
| **车流有车型** | 街上跑 8 种车：私家车（随机配色）/ 网约车 / 快递车 / 公交车 / 警车 / 救护车 / 环卫车 / 电动车。公交只跑中央大道与南环路，警车蓝灯、救护车红灯会闪且更快，快递车和环卫车慢一些；并按路段加权：靠近快递站/超市的路段快递车更多、派出所附近警车更多 |
| **街区 88×48** | 东扩 20 格：新增东商业街（快递站/奶茶店从马路上接下来）、东公园、篮球场与儿童乐园东移。地块按 16×16 分块惰性生成，扩图不增加开局开销 |
| **街区可读** | 每栋商铺和公共建筑头顶都有招牌（8 格内显示，近实远淡），不用再靠记忆猜哪栋是银行；招牌画在灯光之后，夜里也亮着 |
| **第一次引导** | 「生活目标」面板最上面是一条 11 步顺序链：出门 → 吃饭 → 上班 → 摆家具 → 换地板墙纸 → 存钱 → 搬新家 → 下馆子 → 养宠物 → 卖房 → 股市盈利。一次只推一件，做完压成一行 ✓ 并自动推进；每一步带一句"具体怎么做"，底部提示条也会顺手提一句 |
| **银行与股市** | 民生银行：活期 0.2%/天（上限 50 万）、30/90 天定期、三档贷款（每天自动扣、逾期只扣情绪不没收房产）；证券营业部：6 支股票，价格由「股票序号+游戏日」稳定散列推导，同日全服一致、可复现。漂移有正有负（地产/博彩长期阴跌）、另带 60–150 天的季节周期，所以**看图择时比闭眼持有更划算** |
| **画面细节** | 切场景有一层 0.26 秒黑场（不硬跳）；店招是块木牌，商铺木色、公共建筑冷灰；状态跌破警戒时整行轻轻呼吸；所有画布文字统一字体栈（中文字形不再掉到衬线体） |
| **网购与取件** | 家里点「商店」可以切到「网购 · 88 折，次日到快递站」：下单只扣钱、货**次日**到快递站，自己走过去取才进仓库。到货当天会播一句提醒；地图东边那条街因此有了第二个去处的理由。在途包裹进存档的 `parcels` 字段，只存 `{id, price, orderedDay, readyDay}`，到没到由日期算 |
| **声景** | 全部用 WebAudio 现场合成，**零音频文件**、离线可玩：小区有风与鸟鸣（入夜转虫鸣）、家里有极轻的房间底噪、下雨自动压掉风声；音高与音量带随机抖动，同一个按钮点十次不会听见十次完全一样的音；统一主总线带限幅，连点不爆音 |
| **对话参数集中** | 气泡字号/宽度/行高/尖角/颜色/淡入淡出、每句停留时长、闲聊重试间隔、问路范围全在 `content/ui/talk.json`；引擎侧有默认值兜底，内容缺了也能跑。V4.33 卡合理区间（行高小于字号、重试 0 分钟这种当场报） |
